# 수요 분석 대시보드 (포트폴리오)

SCM 수요 계획 업무에서, 결품 기간의 판매 때문에 옵션/컬러 비중이 실제 수요보다 낮게 잡히는 문제를 풀려고 기획하고 만든 대시보드의 사례 소개입니다.

**소개 페이지:** https://kangleam.github.io/demand-analysis-dashboard-demo/

- 역할: 기획, 요구사항 정의, 검증 (구현은 AI 코딩 도구 Claude Code와 함께)
- 기간: 2026.09 – 2026.11
- 내용: 풀려던 문제, 세 화면(상품 순위, 출고량, 비중), 결품 보정, 숫자의 정의를 정한 기록, 사내 포털 이관과 검증

페이지의 화면은 모두 가상 브랜드, 가상 상품, 가상 거래처로 만든 데모 데이터입니다. 실제 회사 데이터와 코드는 이 저장소에 없습니다.

`index.html` 한 파일에 그림과 글꼴이 모두 들어 있어, 내려받아 브라우저로 바로 열어 볼 수도 있습니다.
